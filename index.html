Privacy Policy

Lovely Finds Social Publisher
Last updated: 12 November 2026

This policy is provided in English and Portuguese. The application is a private, owner-operated integration for managing the owner's own Pinterest account. It is not offered as a public service to other users.

1. Who operates the application and its purpose

Lovely Finds Social Publisher is operated by the owner of the Lovely Finds project for personal use. It connects to the owner's Pinterest account through the Pinterest API to view account boards and Pins, retrieve permitted account or Pin analytics, and create, schedule, or manage Pins where the Pinterest app's access level and granted OAuth permissions allow those actions. Production access is kept separate from Sandbox testing. The application does not provide account access to the public or to other customers.

2. Information processed

Depending on the feature used and the permissions granted by Pinterest, the application may process:

  • Pinterest account information made available by the authorised API, such as account identifiers and profile details.
  • Board names and identifiers, and Pin identifiers, titles, descriptions, destination links, image references and creation details.
  • Aggregated account and Pin analytics made available by Pinterest, such as impressions, engagements, Pin clicks, outbound clicks and saves.
  • Content supplied by the owner for a Pin, including its title, description, destination URL, image URL, selected board and scheduled publication time.
  • Technical information generated by GitHub Actions, such as workflow status and execution logs.

The application does not intentionally request or collect Pinterest users' passwords. Authentication is performed through Pinterest OAuth.

3. How information is used

Information is used only to operate the owner's requested Pinterest workflow: selecting boards, reviewing existing Pins, preparing and publishing Pins, scheduling publication, and viewing the analytics that Pinterest makes available to the authorised account. The owner initiates and reviews actions. The application does not sell Pinterest information, build advertising profiles, or use it for independent advertising or marketing.

4. Where information is processed and stored

The integration uses GitHub Actions to run its automation. Pin content and scheduling requests may be placed in GitHub Issues in the project's private repository so the workflow can validate and process them. Generic processing statuses may be added as Issue comments. GitHub Actions logs may contain execution status and diagnostic messages. The application is designed not to write Pinterest API response catalogues, account analytics results, or Pin response data into Issue comments or workflow outputs.

OAuth refresh tokens and application credentials are stored as encrypted GitHub Actions Secrets, not in public source code or Issue payloads. Pinterest access tokens are used by the workflow to make authorised API requests. The application does not maintain a separate public user database. GitHub processes repository content, Issues, Secrets and workflow logs under GitHub's own services and retention practices.

Images may be hosted by a service selected by the owner, such as Dropbox. In that case, the workflow sends the image URL to Pinterest; the hosting provider processes the image under its own terms. Destination links may lead to third-party websites, such as online retailers. Those websites are governed by their own privacy policies.

5. Sharing and disclosure

Information is transmitted to Pinterest when needed to perform the requested API operation. GitHub processes the information required to host the private repository and run the automation. An image-hosting provider may process images selected by the owner. The application does not sell information or share Pinterest account data with third parties for their own advertising or marketing. The application is intended for one owner's use and does not disclose account data to other application users.

6. Retention and deletion

Pin requests and their content may remain in the private GitHub repository's Issues and comments until the owner deletes them. Workflow logs are retained according to the repository's GitHub Actions settings and GitHub's applicable retention rules. OAuth refresh tokens remain in GitHub Actions Secrets until the owner replaces or removes them. The application does not keep a separate analytics database; analytics are requested from Pinterest when needed and are not intentionally persisted in workflow comments or outputs.

The owner can delete request Issues and related content from the repository, remove stored GitHub Secrets, and revoke the application's authorisation from Pinterest account settings. Deleting an Issue or Secret does not necessarily remove copies already retained by GitHub under its backup, security, or service-retention processes. Privacy questions or requests concerning information controlled by the application can be sent to the contact below.

7. Security

The repository is intended to remain private. Access is restricted through GitHub account permissions and an authorised-actor check in the workflow. Credentials are stored as encrypted GitHub Actions Secrets and are not intended to be placed in Issues, comments, commits or public files. Separate credentials and API environments are used for Sandbox and production. Reasonable technical and organisational safeguards are applied, but no internet service can guarantee absolute security.

8. Pinterest and third-party services

The application uses the Pinterest API and is subject to Pinterest's applicable developer terms, policies and API permissions. Pinterest independently processes information under its own Privacy Policy. GitHub and any image-hosting or destination website also process information under their own terms. Lovely Finds is an independent project and is not affiliated with, sponsored by, or endorsed by Pinterest.

9. Changes to this policy

This policy may be updated when the application's features or data practices change. The current version and its update date will be published at this URL.

10. Contact

For privacy questions or requests concerning information controlled by this application, contact:

Política de Privacidade

Lovely Finds Social Publisher
Última atualização: 12 de novembro de 2026

1. Quem opera o aplicativo e sua finalidade

O Lovely Finds Social Publisher é operado pela proprietária do projeto Lovely Finds para uso próprio. Ele se conecta à conta Pinterest da proprietária por meio da API do Pinterest para consultar quadros e Pins, obter métricas de conta ou de Pins permitidas e criar, agendar ou gerenciar Pins quando o nível de acesso do aplicativo e as permissões OAuth concedidas permitirem. O acesso de produção é separado dos testes no Sandbox. O aplicativo não é oferecido ao público nem a outros clientes.

2. Informações processadas

Dependendo do recurso utilizado e das permissões concedidas pelo Pinterest, o aplicativo pode processar informações da conta disponibilizadas pela API; nomes e identificadores de quadros; identificadores, títulos, descrições, links, referências de imagens e datas dos Pins; métricas agregadas disponibilizadas pelo Pinterest, como impressões, engajamentos, cliques no Pin, cliques de saída e salvamentos; e dados fornecidos pela proprietária para criar ou agendar um Pin, como título, descrição, link, URL da imagem, quadro e horário de publicação. Também podem ser processados dados técnicos de execução do GitHub Actions, como status e logs.

O aplicativo não solicita intencionalmente as senhas dos usuários do Pinterest. A autenticação é realizada pelo OAuth do Pinterest.

3. Como as informações são utilizadas

As informações são utilizadas exclusivamente para executar o fluxo de trabalho Pinterest solicitado pela proprietária: selecionar quadros, consultar Pins existentes, preparar e publicar Pins, agendar publicações e visualizar as métricas disponibilizadas pelo Pinterest à conta autorizada. A proprietária inicia e revisa as operações. O aplicativo não vende informações do Pinterest, não cria perfis publicitários e não utiliza esses dados para publicidade ou marketing independente.

4. Onde as informações são processadas e armazenadas

A integração utiliza o GitHub Actions para executar as automações. Solicitações de Pins e dados de agendamento podem ser registrados em GitHub Issues no repositório privado do projeto para que o workflow valide e processe as solicitações. Comentários podem registrar status genéricos de processamento. Os logs do GitHub Actions podem conter status de execução e mensagens técnicas. O aplicativo foi projetado para não gravar catálogos de respostas da API do Pinterest, resultados de métricas da conta ou dados de resposta de Pins em comentários de Issues ou saídas do workflow.

Tokens de atualização OAuth e credenciais do aplicativo são armazenados como GitHub Actions Secrets criptografados, e não no código-fonte público ou nos dados das Issues. Tokens de acesso do Pinterest são utilizados pelo workflow para realizar chamadas autorizadas à API. O aplicativo não mantém um banco de dados público separado de usuários. O GitHub processa o conteúdo do repositório, Issues, Secrets e logs conforme seus próprios serviços e regras de retenção.

As imagens podem ser hospedadas em um serviço escolhido pela proprietária, como o Dropbox. Nesse caso, o workflow envia a URL da imagem ao Pinterest, e o provedor de hospedagem processa a imagem conforme seus próprios termos. Links de destino podem direcionar a sites de terceiros, como lojas virtuais, sujeitos às respectivas políticas de privacidade.

5. Compartilhamento e divulgação

As informações são transmitidas ao Pinterest quando necessário para executar a operação solicitada pela API. O GitHub processa as informações necessárias para hospedar o repositório privado e executar as automações. Um provedor de hospedagem pode processar imagens escolhidas pela proprietária. O aplicativo não vende informações nem compartilha dados da conta Pinterest com terceiros para publicidade ou marketing próprios. O aplicativo é destinado ao uso de uma única proprietária e não disponibiliza os dados da conta a outros usuários do aplicativo.

6. Retenção e exclusão

Solicitações de Pins e seu conteúdo podem permanecer nas Issues e comentários do repositório privado até que a proprietária os exclua. Os logs de workflow são retidos conforme as configurações do GitHub Actions e as regras de retenção aplicáveis do GitHub. Tokens OAuth permanecem nos GitHub Actions Secrets até serem substituídos ou removidos pela proprietária. O aplicativo não mantém um banco de dados separado de métricas; as métricas são consultadas no Pinterest quando necessário e não são intencionalmente persistidas em comentários ou saídas do workflow.

A proprietária pode excluir Issues e conteúdos relacionados do repositório, remover GitHub Secrets e revogar a autorização do aplicativo nas configurações da conta Pinterest. A exclusão de uma Issue ou Secret não garante a remoção de cópias que o GitHub possa manter por motivos de backup, segurança ou retenção do serviço. Dúvidas ou solicitações de privacidade relacionadas às informações controladas pelo aplicativo podem ser enviadas ao contato abaixo.

7. Segurança

O repositório deve permanecer privado. O acesso é limitado pelas permissões da conta GitHub e por uma verificação do autor autorizado no workflow. As credenciais são armazenadas como GitHub Actions Secrets criptografados e não devem ser inseridas em Issues, comentários, commits ou arquivos públicos. Credenciais e ambientes de API separados são utilizados para Sandbox e produção. São adotadas medidas técnicas e organizacionais razoáveis, mas nenhum serviço na internet pode garantir segurança absoluta.

8. Pinterest e serviços de terceiros

O aplicativo utiliza a API do Pinterest e está sujeito aos termos, políticas e permissões de API aplicáveis do Pinterest. O Pinterest processa informações de forma independente conforme sua própria Política de Privacidade. O GitHub e quaisquer serviços de hospedagem de imagens ou sites de destino também processam informações conforme seus próprios termos. Lovely Finds é um projeto independente, sem afiliação, patrocínio ou endosso do Pinterest.

9. Alterações nesta política

Esta política poderá ser atualizada quando os recursos ou as práticas de dados do aplicativo mudarem. A versão atual e sua data de atualização serão publicadas neste endereço.
